## Согласование исходных материалов

1. ER не содержит total_price и оплаты; до 2.2 исходный текст не изменён. В 2.2 пояснено вычисляемое Total и фиксация факта оплаты через статус.
2. Неизменённые varchar и text требуют кириллической кодировки базы. Скрипт создаёт Cyrillic_General_100_CI_AS.
3. В FINAL пример другой предметной области с восемью таблицами. Количество таблиц не переносится на фотостудию: её модель содержит семь.
4. MR приводит общие правила приложений, шаблон — конкретные А–Д; сохранена структура приложений шаблона.
5. Основная часть исходного автора занимает значительный объём. Дополнение с обязательными снимками увеличивает число страниц; требование 20–25 страниц нельзя гарантировать без сокращения сохранённой части.
6. Записка показывает фактический статус, а не выдуманные положительные серверные испытания. Все 36 серверных сценариев пройдены на Linux; на Windows требуется повторить VERIFY_SQL_SERVER.bat, проверив свой экземпляр и права. Серверные снимки уже включены.
